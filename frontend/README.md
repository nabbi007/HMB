# HMB Frontend (Next.js PWA)

Mobile-first, installable web app for HelloMamaBetter. Talks to the FastAPI backend.

## Run

```bash
cd frontend
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_API_URL if backend isn't on :8000
npm run dev
```

Open http://localhost:3000. The landing page calls the backend `/health` endpoint and
shows its status, which confirms the API client is wired correctly. (Start the backend
first: `docker compose up` from the repo root.)

## Scripts

- `npm run dev` — dev server
- `npm run build` / `npm start` — production build & serve
- `npm run lint` — ESLint (Next + TS + Prettier rules)
- `npm run format` — Prettier write

## PWA

- **Manifest:** generated by `src/app/manifest.ts` at `/manifest.webmanifest` (auto-linked).
- **Service worker:** `public/sw.js`, registered by `src/components/ServiceWorkerRegister.tsx`.
  It only activates in a **production build** (`npm run build && npm start`) — this is
  intentional so dev hot-reload isn't fought by the SW cache.
- **Icons:** `src/app/icon.svg` is the favicon. For full installability you must add raster
  icons (see `public/icons/README.md`).

## Structure

```
src/
  app/
    layout.tsx      # root layout, viewport/theme, mounts SW registration
    page.tsx        # landing page (proves backend wiring)
    globals.css     # mobile-first app-shell styles
    manifest.ts     # PWA manifest
    icon.svg        # favicon / app icon source
  components/        # React components
  lib/
    api.ts          # typed fetch client (bearer token, ApiError)
    config.ts       # env-driven config
```
